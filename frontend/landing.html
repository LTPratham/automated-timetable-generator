Formal Theory

Mathematical Problem Formulation

Formalized as a discrete 3-tuple (X, D, C) meeting university academic standards.

1. Variables (X)

Each course session block is an atomic variable:

X = { S_{c, b, t, k} } | c ∈ Courses, b ∈ Batches, t ∈ {Theory, Lab}, k ∈ SessionIndex

2. Permissible Domains (D)

Permissible slot-room assignments:

D_i ⊆ { (d, s, r) | d ∈ Days, s ∈ Slots, r ∈ Rooms }

3. Hard Constraints (Zero-Tolerance)

No faculty double-booking, no classroom overlap, no student cohort overlap, capacity verification (Capacity(r) ≥ Enrollment(b)), and lab room qualification.
