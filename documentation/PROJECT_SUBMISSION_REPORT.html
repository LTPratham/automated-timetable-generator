📋 Project Abstract

University timetabling is a classic NP-hard Constraint Satisfaction Problem (CSP). Our system automatically generates conflict-free, optimised academic timetables by encoding hard constraints (no-clash, room capacity, faculty availability) into a CSP framework and solving them using four complementary AI paradigms: Backtracking with MRV heuristic, CP-SAT via Google OR-Tools, Simulated Annealing, and a custom Genetic Algorithm. The interactive web dashboard provides real-time constraint-violation highlighting, step-by-step search traces, Responsible AI fairness audits, what-if rescheduling, PDF/Excel/iCal exports, and a 9-step guided tour for new users.
